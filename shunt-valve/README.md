# ShuntView

션트 밸브 판독 보조 기술의 사용 흐름을 보여주는 정적 인터랙티브 프로토타입.

## 실행

`index.html`을 브라우저에서 열거나 저장소 루트에서 `python -m http.server 8000`을 실행하고 `/shunt-valve/`에 접속합니다. 빌드 과정이나 서버 API가 필요하지 않습니다. GitHub Pages에 그대로 게시할 수 있습니다.

## 기능

- 설명용 정면·측면 예시 영상
- 영역 검출 → 방향 정렬 → 조절 단계 표시의 단계별 시연
- 각 단계 직접 이동, 재생·초기화, 영상 확대, 전체 화면
- PNG/JPG/WebP 로컬 미리보기: 파일당 최대 15 MB
- 데스크톱·태블릿·모바일 반응형 화면

## 시연과 실제 추론의 구분

학습 모델과 추론 API는 포함하지 않습니다. 예시의 밸브 위치 및 PL 1.0은 사전 설정된 시연 값이며 영상에서 추론한 결과가 아닙니다. 임의의 업로드 영상에는 결과를 생성하지 않습니다. 파일은 브라우저 메모리에서만 처리하며 전송·저장하지 않습니다. DICOM은 지원하지 않습니다.

예시 SVG는 이 프로토타입을 위해 새로 작성한 가상 두개골·밸브 벡터 도식입니다. 실제 환자 영상이나 첨부 문서에서 추출한 영상은 공개 파일에 포함하지 않습니다. 해당 예시는 원본 AP 화면의 오른쪽에 밸브를 배치했습니다. 방향 정렬 도식은 AP 좌우 반전, 측면 반전 미적용 조건을 설명합니다. 각 화면의 도식은 실제 영상의 검출·정렬 결과가 아닙니다.

실제 모델 연결 시에는 검출 좌표, 정렬 영상, 조절 단계의 출처를 분리하고 실제 입력 영상에 대한 추론이 완료되기 전에는 결과를 표시하지 않아야 합니다. 의료영상 처리 및 검증은 별도 구현이 필요합니다.

이 폴더는 기존 개인 홈페이지와 독립적으로 동작합니다.
